# 🏸 예약콕 (ReservationKOK)

> 배드민턴 코트 예약부터 예약 관리까지 한 번에 가능한 웹 예약 관리 프로그램

## 📖 프로젝트 소개

예약콕은 사용자가 원하는 날짜와 시간에 배드민턴 코트를 예약하고,
예약 내역을 조회 및 취소할 수 있는 배드민턴 코트 예약 관리 프로그램입니다.

관리자는 코트와 예약 정보를 효율적으로 관리할 수 있으며,
회원은 실시간 예약 현황을 확인하여 원하는 시간대의 코트를 예약할 수 있습니다.
